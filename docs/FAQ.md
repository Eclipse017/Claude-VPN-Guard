# 常见问题

[使用教程](USER-GUIDE.md) · [返回首页](../README.md)

## 一键安装后就有保护了吗？

应用安装不等于系统保护已启用。需要继续完成中文向导中的节点、分流和出口检查，再确认管理员提示。请以向导显示的成功状态为准。

## 不显示书娘还能保护吗？

可以。桌宠是交互界面，已经启用的后台保护独立运行，退出桌宠不会解除它。

## 会自动打开 Claude 吗？

安装、配置和日常桌宠互动都不会自动打开 Claude。需要用户自行选择独立的受保护启动入口。

## 启动前会检查什么？

程序核验 FlClash 核心、TUN、路由、节点身份、实时分流规则、DNS、出口 IP 与地区，以及 Claude 专用网络规则。失败、超时、未知或过期证据会导致启动被拒绝。

后台会持续复核。发现检查失效时可能结束受保护的 Claude 包进程，未保存内容可能丢失。

## 网络规则怎样工作？

使用 Windows 自带的 WFP，对支持的 Claude 包身份与包内程序施加应用级规则。保留本机代理和指定 TUN 通路，限制其他接口上的直接联网。

其他应用的既有保护规则不由本组件修改。本地代理后续如何转发，仍取决于 FlClash 的实际分流与节点设置。

## 地区检查能保证账号安全吗？

不能。中立 HTTPS 探针只核验其自身出口与代理链，不是对 Claude 服务的端到端访问测试，也不能认证账号或实际所在地资格。

这不是防封号工具，不保证零泄漏、账号安全或服务可用性。本地管理员可以更改保护设置。

## 哪些场景不在当前范围内？

网页版、独立 CLI、通用解释器、其他设备与 Cowork 虚拟机不在完整覆盖范围内。当前配置要求关闭 IPv6；复杂订阅及只有 provider 引用的配置暂不支持。

## 当前版本验证到什么程度？

已完成策略检查、离线替身、隔离目录安装与卸载、向导和桌宠交互的验证。全新电脑的系统保护安装、真实 Claude 运行兼容性、系统重启与真实 VPN 中断场景尚未完成完整验证。

因此当前版本保留预发布标记，不作为适用于所有机器与客户端版本的保证。

## 为什么会提示地区名单过期？

可用地区会变化。本版名单核对日为 2026-10-25，有效至 2027-01-23 UTC；到期锁定后需更新版本。出口 IP 或节点变化时也需要重新检查。

## 会上传我的节点配置吗？

节点配置和接口密钥在本机读取，未包含在仓库或图文素材包中。中立出口检查会产生对固定探针站点的网络请求。配置备份可能包含私人信息，不要上传或分享备份原件。

## 已有其他启动保护器怎么办？

本版不直接覆盖旧 ClaudeVpnGuard 或未知保护组件。请保留原保护，先阅读它的迁移或卸载说明。

优先下载 **ShuniangGuard-0.2.0-preview.1-Setup.exe**，双击安装后按中文向导设置。

- 自带运行环境，不依赖旧版 ClaudeVpnGuard；启用系统保护需要一次管理员确认。
- 中文节点选择、专属分流备份、出口地区检查；不支持、未知或过期地区拒绝放行。
- 桌宠默认安静，拖动后停住；可退出桌宠并保留后台保护。
- 只支持 Windows x64 + FlClash + Windows 商店版 Claude。复杂订阅、IPv6 等不在当前支持范围。

此版本为预发布。安装文件校验、隔离解压/卸载、向导及离线策略测试已执行；全新机器系统服务安装、真实 Claude 启动与运行兼容性未验证。开发与测试没有启动 Claude。请阅读仓库 README 的完整要求和限制。

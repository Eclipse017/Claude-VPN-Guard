书娘守护：会互动的桌面小书娘 📚

一键安装、中文向导、本地互动，日常使用从这三件事开始。

① 一键安装
运行环境已包含在安装包里，无需另行配置，也不依赖旧版保护程序。双击安装后，就能进入中文向导。

② 中文向导
读取节点、备份专属分流、检查出口地区，按步骤操作。启用系统保护还需要完成检查，并确认 Windows 管理员提示。应用安装完成不等于保护已启用。

③ 桌宠互动
单击打招呼、摸摸头、右键一起读书。平时安静待着，拖动松手后停住，不会满屏飞。互动在本机运行，无需模型密钥。

系统保护成功启用后，会在启动前核验节点、分流、出口地区和网络规则；失败、超时或无法确认时，按策略拒绝启动。普通点击、摸头、安装和配置都不会自动打开 Claude。

不想显示桌宠也可以退出，已启用的后台保护继续运行。简单使用步骤放在第 6 张图。

当前为预发布版，仅支持指定的 Windows x64 + FlClash + Windows 商店版 Claude 场景。全新电脑的系统保护安装和真实 Claude 运行兼容性尚未完成完整验证。它不保证零泄漏或账号安全，也不作为“防封号工具”宣传。

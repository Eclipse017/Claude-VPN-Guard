# 小红书内容草稿

标题：做了一只会摸头回应的小书娘，还会帮忙检查网络

正文：

这次把桌宠做成了 Windows 独立安装包。下载后双击安装，按中文向导选节点、检查出口地区和分流，不用另外装运行环境，也不需要旧版保护程序。

小书娘可以打招呼、摸头、陪着看书。平时安静待着，拖动后停住，不会满屏飞。互动在本地运行，不需要模型 Key。

她的实用功能是启动前检查：网络、节点、分流和出口地区全部符合设定才放行；不支持地区、配置不对、检查超时或后台失联就先锁住。还有只针对 Claude 的网络规则，限制绕过指定 TUN 的直连。

不想显示桌宠也可以退出，后台保护继续。安装、配置、点击和摸头都不会自己打开 Claude。

目前是预发布版：向导与离线测试已完成，全新机器的系统服务安装和真实客户端兼容性仍待验证。开发测试没有打开 Claude，也没有切断正在使用的 VPN。它不是防封号工具，不保证零泄漏。

桌宠底层来自开源 dsh-pet，保留原作者署名。书娘素材为 AI 生成，代码和安装包公开在 GitHub。

# 小红书内容草稿

标题：给桌面养了个小书娘，还让她帮我看启动检查

正文：

最近把桌宠和自己用的网络检查程序接到了一起。

这只橙发小书娘可以拖动、摸头、打招呼，也能陪着看书。平时的互动都在本地运行，不需要填模型 Key。

我给她加了一个实用功能：打开 Claude 前，先检查 TUN、节点选择、分流规则和出口。检查失败、超时，或者后台没有回应，就先锁住启动入口，面板里会显示原因。

她不会自己打开 Claude。普通点击和摸头只做互动，启动是面板里的独立按钮。

目前还是预发布版本。展示的是实际桌宠和离线测试界面；真实 Claude 启动没有参与测试。它不是“防封号工具”，也不保证零泄漏。

桌宠底层来自开源项目 PC2005-cloud/dsh-pet，我做了书娘素材、交互适配和保护检查，保留了原项目署名。
